# KYAF খাদ্য দান ব্যবস্থাপনা সিস্টেম — ইনস্টলেশন ও ব্যবহার নির্দেশিকা (বাংলা)

এই প্রকল্পটি **Laravel 11 + PHP 8.2 + MySQL + Bootstrap 5** দিয়ে তৈরি। এটি **Windows + WAMP + VS Code** এ চলে।
আপনাকে কোনো কোড লিখতে বা ফাইল তৈরি করতে হবে না।

> 📌 **সততার সাথে জানাচ্ছি:** এই প্রকল্পটি যে পরিবেশে তৈরি হয়েছে সেখানে PHP/Composer/MySQL চালানোর সুযোগ ছিল না। তাই কোডটি **সিস্টেমে চালিয়ে পরীক্ষা করা হয়নি**। কী কী যাচাই হয়েছে আর কী হয়নি তা নিচে "পরীক্ষার অবস্থা" অংশে স্পষ্ট করে লেখা আছে। প্রথমবার চালানোর সময় ছোটখাটো ত্রুটি আসতে পারে — "সমস্যা সমাধান" অংশ দেখুন।

## ২) ইনস্টলেশন — ধাপে ধাপে

### ধাপ ১: ZIP এক্সট্র্যাক্ট করুন
`KYAF_Food_Donation_Management_System.zip` ফাইলটি **`C:\wamp64\www\`** ফোল্ডারে এক্সট্র্যাক্ট করুন।
ফলে ফোল্ডারটি হবে: `C:\wamp64\www\KYAF_Food_Donation_Management_System`

### ধাপ ২: VS Code এ খুলুন
VS Code → **File → Open Folder** → উপরের ফোল্ডারটি বেছে নিন।

### ধাপ ৩: WAMP চালু করুন
WAMP Server চালু করুন। নিচের ডান কোণার ট্রে আইকনটি **সবুজ** হলে ঠিক আছে (লাল/কমলা হলে "সমস্যা সমাধান" দেখুন)।

### ধাপ ৪: ডেটাবেজ তৈরি করুন
1. ব্রাউজারে খুলুন: **http://localhost/phpmyadmin** (ইউজার `root`, পাসওয়ার্ড ফাঁকা)।
2. বাঁ পাশে **New** চাপুন।
3. Database name: **`kyaf_food_donation`**
4. Collation: **`utf8mb4_unicode_ci`** → **Create** চাপুন।

### ধাপ ৫: VS Code টার্মিনাল খুলুন
VS Code এ **Terminal → New Terminal** (শর্টকাট: Ctrl + `)।
টার্মিনাল **Command Prompt** হলে সবচেয়ে ভালো (PowerShell এ সমস্যা হলে নিচের তীর চিহ্ন থেকে "Command Prompt" বাছুন)।

### ধাপ ৬ (সবচেয়ে সহজ): এক কমান্ডে সব সেটআপ
টার্মিনালে এই কমান্ডটি কপি-পেস্ট করে Enter চাপুন:
```
setup.bat
```
এটি স্বয়ংক্রিয়ভাবে করবে: `.env` ফাইল তৈরি → Composer প্যাকেজ ইনস্টল → অ্যাপ কী → ডেটাবেজ টেবিল তৈরি → ডিফল্ট রোল/অ্যাডমিন/ডেমো ডেটা → ক্যাশ পরিষ্কার।
**`setup.bat` কখনো আপনার ডেটা মুছে ফেলে না**, তাই একাধিকবার চালালেও নিরাপদ।

### ধাপ ৬ (বিকল্প): হাতে হাতে কমান্ড
`setup.bat` কাজ না করলে একটি একটি করে এই কমান্ডগুলো চালান:
```
copy .env.example .env
composer install
php artisan key:generate
php artisan migrate --force
php artisan db:seed --force
php artisan optimize:clear
```
> **`.env` ফাইলে ডেটাবেজ সেটিং:** ডিফল্ট সেটিং (`DB_DATABASE=kyaf_food_donation`, `DB_USERNAME=root`, `DB_PASSWORD=` ফাঁকা) WAMP এর ডিফল্টের সাথে মিলে যায়, তাই সাধারণত কিছু বদলাতে হয় না। আপনার MySQL এ root এর পাসওয়ার্ড দেওয়া থাকলে `DB_PASSWORD=` এর পর সেটি লিখে Save করুন।
> **যদি `php` বা `composer` চেনা না যায়:** `setup.bat` নিজেই `C:\wamp64\bin\php\php8*` এ PHP খুঁজে নেয়। হাতে চালালে আগে `set PATH=C:\wamp64\bin\php\php8.2.26;%PATH%` (আপনার ভার্সনের ফোল্ডার নাম দিন) চালান।

### ধাপ ৭: ওয়েবসাইট চালু করুন
```
start.bat
```
(অথবা: `php artisan serve`)। টার্মিনাল উইন্ডোটি **খোলা রাখুন**।

### ধাপ ৮: ব্রাউজারে খুলুন
👉 **http://127.0.0.1:8000**

লগইন তথ্য: **`DEMO_ACCOUNTS.md`** ফাইলে আছে। অ্যাডমিন: `admin@kyaf.local` / `Admin@12345`

## ৩) সার্ভার বন্ধ ও আবার চালু
- **বন্ধ:** টার্মিনালে **Ctrl + C** চাপুন (বা উইন্ডো বন্ধ করুন)।
- **আবার চালু:** `start.bat`

- **WAMP এর মাধ্যমে (সার্ভার কমান্ড ছাড়া):** `http://localhost/KYAF_Food_Donation_Management_System/public` — এর জন্য Apache এ `rewrite_module` চালু থাকতে হবে। সহজতম পথ `start.bat`।

## ৪) বাংলাদেশের প্রকৃত এলাকা-তথ্য যোগ করা (গুরুত্বপূর্ণ)
সিস্টেমে ইচ্ছা করে শুধু **"ডেমো"** নামের এলাকা আছে — আমরা বানিয়ে কোনো আসল জেলা/থানার নাম বসাইনি। প্রকৃত তথ্য যোগ করতে:
1. সরকারি/নির্ভরযোগ্য উৎস থেকে বিভাগ-জেলা-উপজেলা-থানার তালিকা নিয়ে এই কলামসহ একটি **UTF-8 CSV** বানান:
   `division, district_en, district_bn, upazila_en, upazila_bn, thana_en, thana_bn`
   (নমুনা: `public/locations_template.csv`)
2. অ্যাডমিন হিসেবে লগইন → **অবস্থান (বিভাগ–থানা)** → "CSV থেকে ইমপোর্ট" → ফাইল বেছে ইমপোর্ট করুন।
3. এরপর **সেবা এলাকা** পাতা থেকে থানাগুলো সেবা এলাকায় ভাগ করে দিন এবং এরিয়া ম্যানেজার নিয়োগ দিন।
   (একটি থানা একাধিক সেবা এলাকায় রাখা যায় না।)

## ৫) প্রধান বৈশিষ্ট্য (SRS অনুযায়ী)
- **চারটি ভূমিকা:** অ্যাডমিন, এরিয়া ম্যানেজার, স্টাফ, দাতা — আলাদা লগইন পাতা (লগইন বোতামে পপআপ), আলাদা ড্যাশবোর্ড ও মেনু; URL বদলে অন্যের পাতায় ঢোকা যায় না (৪০৩ + অডিট লগ)।
- **নিরাপত্তা:** bcrypt পাসওয়ার্ড, শক্তিশালী পাসওয়ার্ড নীতি (৮–৬৪ অক্ষর, বড়/ছোট হাতের অক্ষর, সংখ্যা, বিশেষ চিহ্ন, শেষ ৩টি আবার নয়), ৫ বার ভুলে ১৫ মিনিট লক, ৩০ মিনিট নিষ্ক্রিয়তায় সেশন শেষ, CSRF, সার্ভার-সাইড যাচাই, লগইনে সেশন নবায়ন, লগইন রেট-লিমিট, অডিট লগ (মোছা/বদলানো যায় না)।
- **দাতা নিবন্ধন:** ইমেইল/বাংলাদেশি মোবাইল যাচাই (`01XXXXXXXXX`, `+8801XXXXXXXXX`, `8801XXXXXXXXX` — সব `+8801XXXXXXXXX` এ রূপান্তরিত), দেখান/লুকান পাসওয়ার্ড বোতাম, আবশ্যিক ঘরে লাল `*`, দাতা আইডি `DNR-000001`।
- **এলাকা নির্বাচন:** বিভাগ → জেলা → উপজেলা → থানা (ডেটাবেজ-চালিত ডিপেন্ডেন্ট ড্রপডাউন)। দান ফর্মে পেশাদার পপআপ; সেবা এলাকার বাইরের থানা নির্বাচন করা যায় না।
- **দানের জীবনচক্র:** জমা → স্টাফ নিয়োগ → যাচাই → অনুমোদন → সংগ্রহ → বিতরণ → সম্পন্ন; এছাড়া প্রত্যাখ্যাত/বাতিল/মেয়াদোত্তীর্ণ। ট্র্যাকিং কোড `DON-2026-000001`, প্রতিটি পরিবর্তনের ইতিহাস (কে, কখন, আগের/পরের অবস্থা, মন্তব্য), ডেটাবেজ ট্রানজ্যাকশন, গুরুত্বপূর্ণ ধাপে মেয়াদ পুনঃযাচাই।
- **স্টাফ নিয়োগ:** জনসমক্ষে আবেদন (NID, বয়স ১৮+, PDF সিভি) → ম্যানেজার পর্যালোচনা → অনুমোদন → ৭২ ঘণ্টার একবার-ব্যবহারযোগ্য আমন্ত্রণ লিংক → স্টাফ অ্যাকাউন্ট। প্রতি ম্যানেজারের দলে সর্বোচ্চ ৫ জন সক্রিয় স্টাফ (ষষ্ঠজন কখনোই নয়)।
- **বিজ্ঞপ্তি, রিপোর্ট (মাসভিত্তিক, এলাকাভিত্তিক, স্টাফ পারফরম্যান্স, CSV), যোগাযোগ বার্তা ব্যবস্থাপনা, সেটিংস, অডিট লগ।**
- **ইন্টারফেস:** সম্পূর্ণ বাংলা, রেসপন্সিভ (ডেস্কটপ/ট্যাবলেট/মোবাইল), বাংলা সংখ্যা (০–৯) টাইপ করলেও কাজ করে।

## ৮) পরীক্ষার অবস্থা (সত্যি তথ্য)
**যা করা হয়েছে:**
- ✅ জাভাস্ক্রিপ্ট (`public/js/kyaf.js`) সিনট্যাক্স পরীক্ষা (`node --check`) — সফল।
- ✅ স্ট্যাটিক যাচাই (নিজস্ব স্ক্রিপ্ট): সব PHP ফাইলে ব্র্যাকেট ভারসাম্য; প্রতিটি রুটের কন্ট্রোলার/মেথড আছে কিনা; প্রতিটি `route('...')` নাম সংজ্ঞায়িত কিনা; প্রতিটি `use`/FQCN ক্লাস আছে কিনা; সব `view()`/`@include`/`@extends` এর ফাইল আছে কিনা; Blade ডিরেক্টিভ (`@if/@endif`, `@foreach`, `@section` ইত্যাদি) মিলছে কিনা; অনুবাদ কী আছে কিনা — **কোনো সমস্যা পাওয়া যায়নি**।
- ✅ কোড লেখার পর হাতে পর্যালোচনা করে বেশ কিছু ত্রুটি (যেমন ambiguous SQL কলাম, ফর্মের বোতাম মান হারানো, সেশন টাইমআউটের ঘড়ি) ঠিক করা হয়েছে।

**যা করা যায়নি (এই পরিবেশে PHP/Composer/MySQL ছিল না):**
- ❌ `composer install`, `php artisan migrate`, সার্ভার চালানো, ব্রাউজারে পাতা খোলা — কোনোটিই চালানো হয়নি।
- ❌ PHPUnit টেস্ট (`tests/` এ ৪৪টি টেস্ট লেখা আছে) **চালানো হয়নি** — তাই "সব টেস্ট পাস" দাবি করা হচ্ছে না।
- ❌ মোবাইল রেসপন্সিভনেস বাস্তব ডিভাইসে দেখা হয়নি (Bootstrap গ্রিড ও মিডিয়া কোয়েরি ব্যবহৃত)।

**আপনি নিজে টেস্ট চালাতে চাইলে:** `run-tests.bat` (ইন-মেমরি SQLite ব্যবহার করে, আপনার MySQL ডেটায় হাত দেয় না; `pdo_sqlite` এক্সটেনশন চালু থাকতে হবে)। কোনো টেস্ট ব্যর্থ হলে বা পাতায় ত্রুটি এলে ত্রুটির বার্তাটি (স্ক্রিনশট/টেক্সট) আমাকে পাঠান — আমি ঠিক করে দেব।
