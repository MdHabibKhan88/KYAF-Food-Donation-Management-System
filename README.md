# KYAF Food Donation Management System

Laravel 11 / PHP 8.2 / MySQL / Bootstrap 5 application built from the KYAF SRS v1.1.
Bangla interface. Four roles: Admin, Area Manager, Staff, Donor.

* Installation (Bangla, step by step): **README_BANGLA.md**
* Demo logins: **DEMO_ACCOUNTS.md**
* Plan, SRS traceability and decisions: **docs/IMPLEMENTATION_PLAN.md**

Quick start (Windows + WAMP): create database `kyaf_food_donation`, then run `setup.bat` and `start.bat`, open http://127.0.0.1:8000.
